    06 / BEFORE YOU APPEAL
    A few things
    worth knowing.
    
      
    Can I play on my phone?+
    The page and downloads work on mobile. The game is designed for a desktop or laptop with a keyboard/controller and a WebGPU-capable browser. There are no touch controls in this build.
    
      
    Do I need the original game?+
    Yes, for this hosted build. Pick a compatible Cricket 07 game folder containing Data, Audio and the executable. The files are copied into your browser’s local storage, not uploaded. The source ZIP contains code and mod resources. The browser-build ZIP also includes the supplied game EXE in a separate game-executable folder. You still need the matching Data and Audio folders; it is not a full-game download.
    
      
    Did you build the browser port from scratch?+
    No. The original browser port is by Dhaiwat Pandya, with contributions credited in that repo, including Stephan Cilliers’ scheduler, netplay and controller work. This project adds the modern squad/kit pack, save-file tools, installation fixes and this page. The source retains the upstream MIT license.
    
      
    What happened to the original teams?+
    OG India and the main senior, county and state sides stay. Eleven A-team/invitational slots become the modern teams in expanded mode. Switch to Original teams to restore every secondary side too. The two modes have separate save folders.
    
      
    Does it save? Can I play online?+
    Native game save files stay in your browser; the launcher provides backup and restore. This is not an instant save-state system, and exhibition matches do not gain a new save-anywhere feature. This public edition is solo/local play; the source includes upstream multiplayer code, which needs its own room server.
    
      
    Can I share or customize this?+
    Absolutely—share this page, download the source and make your own changes. Keep the included licenses and original-port attribution. EA’s game files and team/player trademarks are separate from the open-source code. Cricket 07 and EA Sports belong to Electronic Arts; this is an independent fan project.
